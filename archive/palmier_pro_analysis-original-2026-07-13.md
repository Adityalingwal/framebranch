## Part 1: Palmier Pro

### 1.1 Design Philosophy & Motivation

Palmier Pro was created by a YC startup to address a massive friction point in building AI-generated video projects:
- **The Web-Timeline Iteration Loop:** In traditional pipelines, creators generate clips on web interfaces, download them, import into NLEs (Premiere/DaVinci), trim/place, evaluate, and repeat. Painful.
- **Context Fragmentation:** AI agents are used for scripting (Claude), editing, generating assets (ElevenLabs, Runway), but the NLE itself is a black box to those agents.

**The Palmier Solution:** Turns the NLE timeline into a **read-write interface for AI agents** by exposing an HTTP-based Model Context Protocol (MCP) server at `http://127.0.0.1:19789/mcp`. External LLMs (Claude Code, Codex, Cursor) can query project state, place assets on multi-track timelines, do ripple-deletes, adjust audio, create PIP layouts, add captions, and trigger renders.

### 1.3 Technology Stack

**Rendering Pipeline:**
1. `CustomVideoCompositor` hooks into `AVPlayer` + `AVAssetExportSession`
2. `FrameRenderer` composites tracks bottom-to-top: crop → Metal shaders → transform → opacity → blend
3. Metal `.metal` shaders compiled at build time via `MetalCIKernelPlugin` into Core Image CIKernels

**Timeline Persistence — `.palmier` bundle (macOS document package):**
- `project.json` — frame rate, dimensions, timelines, clips
- `media.json` — imported/generated asset inventory
- `generation-log.json` — AI prompt + generation status history
- `thumbnail.jpg` — autogenerated poster frame
- `media/` — imported + downloaded files
- `chat/` — individual chat history JSONs

### 1.4 MCP Server Tool Catalog

Server runs at: `http://127.0.0.1:19789/mcp`

| Tool | Parameters | Action |
|---|---|---|
| `get_projects` | none | Lists projects with paths and active status |
| `open_project` | `id/name/path` | Opens project; returns framerate, width, height |
| `new_project` | `name` | Creates a `.palmier` bundle in `~/Documents/Palmier Pro` |
| `get_timeline` | `startFrame`, `endFrame`, `captionDetail` | Returns track layout, clip hierarchy, gaps, styles |
| `import_media` | `source` (url/path/bytes/matte), `name`, `folder` | Copies assets to bundle; supports Base64 upload |
| `add_clips` | `entries` (mediaRef, startFrame, duration, sourceRange) | Places video/image/audio onto timeline tracks |
| `set_clip_properties` | `clipIds`, `speed`, `volume`, `opacity`, `transform` | Mutates clip properties |
| `apply_layout` | `layout`, `slots` | Quadrants/PIP/Splits in one command |
| `add_captions` | `animation`, `highlightColor`, `maxWords` | Transcribes + generates word-sync captions |
| `remove_words` | `wordIndices` | Script-based cuts by deleting specific transcript words |
| `remove_silence` | `thresholdDb`, `minDurationMs` | Auto-trims quiet gaps |
| `detect_beats` | `mediaRef` | Computes musical downbeats for cut-to-music |
| `export_project` | `mode` (video/xml/palmier), `outputPath`, `codec` | Renders final output |

### 1.5 Key Constraints & Gotchas

- **No multimodal vision** — Agents connected via MCP are text/code only. Cannot see frames or judge visual quality. Need explicit frame numbers or transcript cues.
- **Drag & Drop rule** — SwiftUI `.onDrop` on parent views shadows all child drop targets on macOS 26. Spanning areas must use AppKit `NSDraggingDestination`. Inner leaf drops can remain SwiftUI.
- **Design System** — All UI uses `AppTheme` constants. Never hardcode spacing, font sizes, radii, colors, or animation durations.
- **Free to run locally** — Zero cloud cost when using local rendering + Apple Speech framework.

## Part 2: Mosaic (mosaic.so)

### 2.1 What Is Mosaic?

Mosaic is a **web-based agentic video editing platform** — often described as "Zapier for Video Editing." It replaces the traditional timeline-first paradigm with a **node-based canvas workflow** where AI agents process footage automatically.

**Tagline:** *"Run video edits on autopilot. A/B test multiple variants from the same raw footage. Then jump into a familiar timeline editor for hands-on creative control."*

Unlike Palmier Pro (where the agent connects externally to a native NLE), Mosaic's AI agent is **built-in and multimodal** — it actually watches, listens to, and understands the video content.

### 2.3 Core Product Architecture

**Mental Model:**
```
Raw Footage → [Node Canvas with Tiles] → Polished Video / NLE Timeline Export
```

An infinite visual canvas where you build editing workflows by connecting "Tiles" — each a discrete operation — into a directed acyclic graph (DAG).

**Tile Categories:**

| Category | Examples |
|---|---|
| **Input** | Video Upload, YouTube Trigger, Google Drive |
| **Creation** | AI Voiceover, B-roll Generator, AI Avatar, AI Music |
| **Action** | Smart Reframe, Background Remove, Auto Caption, Beat Sync, Eye Contact Fix, Smart Trim |
| **Export** | MP4, Premiere Pro XML, DaVinci FCPXML, Final Cut Pro XML |

**What makes it genuinely different:**
1. **Multimodal AI Vision** — The agent actually *watches* the video. Understands shot type, emotion, speech, actions. Selects best takes based on actual content quality, not timecodes you give it.
2. **Parallel A/B Variants** — Generate 10+ versions from the same raw footage simultaneously.
3. **API-First** — Trigger entire workflow via HTTP API: upload footage → run canvas → receive finished MP4.
4. **Human-in-the-Loop** — After the agentic pass, drop into a traditional timeline editor for final polish.

## Part 7: Programmatic DIY Motion-Graphics Pipeline ($0)

If your goal is a **LinkedIn/Twitter cinematic launch teaser** (dynamic typography, kinetic animations, transitions, brand colors, synced beat drops) and you want it completely free without Motion's $5 credit cost, you can build a personal programmatic editing pipeline using **Remotion**.

### 7.1 What is Remotion?
Remotion is an open-source React-based framework that renders videos programmatically. Instead of dragging clips on a timeline, you construct your video elements using standard React components, CSS, and animations, and render it frame-by-frame using a Chromium backend locally on your Mac.

### 7.2 Why Remotion is Ideal for Cinematic Teasers
1. **Perfect Typography Animation:** Since it is web-based, you can use React Spring or CSS transitions to build professional kinetic typography (e.g., word-by-word pop overlays, scaling hooks).
2. **AI Code-Agent Friendly:** Claude Code can generate complete, highly customized Remotion video code templates from a natural language prompt far more efficiently than it can drag coordinates in an NLE interface.
3. **Zero Cost:** The core framework is completely open-source and free for individuals and small startups (under 3 employees) for commercial use.

### Step-by-Step Generation Guide

```
[Claude Code] ── Writes script & voiceover lines
      │
      ├───► Generates audio files via ElevenLabs API (Free 10k chars)
      │     or macOS native `say` command ($0)
      │
      ├───► Pulls stock footage/music from Pexels & Pixabay APIs ($0)
      │
      └───► Scaffolds Remotion project (React + Tailwind CSS)
                  │
                  ▼
            [Local Render] ── Remotion CLI renders video to MP4 locally ($0)
```

#### Step 1: Initialize the Project
Initialize a Remotion repository locally:
```bash
npx create-video@latest fusion-teaser
cd fusion-teaser
```

#### Step 2: Feed the Script to Claude
Command Claude to draft a 30-second kinetic script with brand parameters (e.g., brand colors `#00FFCC` and `#0A0A0F`, bold typography, fast cuts).

#### Step 3: Scaffold the React Components
Claude builds a slide transition component utilizing React Spring:
```tsx
import { Spring, interpolate } from "react-spring";
import { AbsoluteFill, useVideoConfig } from "remotion";

export const SlideTitle = ({ text }) => {
  const { fps } = useVideoConfig();
  return (
    <AbsoluteFill style={{ backgroundColor: "#0A0A0F", justifyContent: "center", alignItems: "center" }}>
      <h1 style={{ color: "#FFFFFF", fontFamily: "Outfit", fontSize: 90 }}>
        {text}
      </h1>
    </AbsoluteFill>
  );
};
```

#### Step 4: Add Sound and Render
Place your downloaded voiceover and Pixabay music files in the `/public` folder of your project, align them inside your React tree using `<Audio />` tags, and render:
```bash
npx remotion render src/index.ts FusionTeaser ~/Downloads/FusionTeaser.mp4
```
